# esp32-projects

## Requirements

- ESP-IDF installed and configured on the test machine
- Espressif ESP-IDF VS Code extension (optional for terminal commands)
- Python 3.10 or newer

The `.vscode/run-idf.sh` launcher is intended for macOS/Linux. It uses
`IDF_PATH` when it is set. Otherwise, it automatically searches for an ESP-IDF
installation in `~/.espressif`. For an installation in another location, set
`IDF_PATH` in the terminal before running a VS Code task.

On Windows, use the ESP-IDF terminal provided by Espressif or the tasks
generated by the ESP-IDF extension.

## Using VS Code

1. Clone the repository and open its root folder in VS Code.
2. Install and configure ESP-IDF for the local machine.
3. Run `Tasks: Run Task`.
4. Choose `Hello World: build` or `LoRa receiver: build`, then the matching
   `flash and monitor` task to flash the board.

The serial port is requested when the flash task starts. `build/` directories
are generated locally and must not be committed.
