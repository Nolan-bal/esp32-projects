# LoRa receiver

Standalone ESP-IDF project for receiving LoRa packets with the LR1121 on the
EoRa-HUB-900TB board and displaying them in the serial console.

## Current parameters

The current implementation uses the following LoRa settings:

- Target: ESP32-S3
- Frequency: 868.125 MHz
- Bandwidth: 125 kHz
- Spreading factor: 9
- Coding rate: 4/5
- Preamble length: 12 symbols
- Maximum payload: 255 bytes
- LoRa sync word: `0x1212`

These values are defined near the top of `main/lora_receiver_main.c` and must
match the transmitter. The code is currently configured for continuous
reception, with a local E80 transmission test enabled every five seconds.

The radio pins are defined at the top of `main/lora_receiver_main.c`.

## Build and flash

From an ESP-IDF terminal:

```sh
cd lora_receiver
idf.py -B build build
idf.py -B build -p PORT flash monitor
```

Exit the monitor with `Ctrl-]`.

The firmware initializes the LR1121 over SPI, checks the BUSY line before each
command, configures the DIO1 interrupt signal, and starts a continuous receive
operation. When DIO1 signals a completed reception, the firmware reads the
payload length and buffer offset, retrieves the payload over SPI, accepts
printable text, and writes it to the serial console.

The current diagnostic output includes startup, LR1121 version, SPI status,
IRQ errors, and test transmissions. A received text payload is displayed as:

```text
[LoRa] hello
```

The transmitter must use the same frequency, bandwidth, spreading factor,
coding rate, sync word, preamble, and implicit/explicit header configuration.

## Current progress and remaining work

Implemented:

- SPI communication with the LR1121.
- GPIO setup for reset, BUSY, and DIO1.
- LR1121 reset, version detection, LoRa packet configuration, and RX startup.
- IRQ polling and RX buffer reads.
- Printable payload filtering before serial output.
- An E80 test transmission generated by the LR1121 for local validation.
- ESP-IDF build, flash, and monitor tasks in the repository workspace.

Still to validate or improve:

- Confirm the final antenna, pinout, and radio settings on the target hardware.
- Validate interoperability with the external E220 transmitter at 868.125 MHz.
- Decide whether the LR1121 E80 test transmission should remain enabled in the
	production configuration.
- Add packet metadata such as RSSI and SNR if the application requires it.
- Add automated hardware tests; the current validation is mainly a successful
	ESP-IDF build and serial-console testing.
